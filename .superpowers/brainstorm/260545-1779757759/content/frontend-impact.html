Login Flow Changes

1. User enters email + password → POST /auth/login
2. Response includes list of user's orgs
3. If 1 org → auto-select, redirect to dashboard
4. If 2+ orgs → show org picker grid
5. User picks org → POST /auth/select-org
6. JWT returned with orgId + role
7. Redirect to dashboard (scoped to that org)
