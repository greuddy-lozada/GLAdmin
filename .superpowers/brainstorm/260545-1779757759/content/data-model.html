Role Resolution Flow

1. User has idRole (base/global role)
2. UserOrganization records override per-org
3. When user picks an org:
   JWT stores: { sub, orgId, roleId }
   roleId = UserOrganization.roleId
         ?? User.idRole (fallback)
4. RolesGuard reads org-scoped role from JWT
5. Super admin (master role): bypasses org filter
