Implementation Phases

Build order, each phase is deployable

Phase 1: Foundation (Schema + Middleware)
1. Create Organization, Plan, UserOrganization models in Prisma
2. Add organizationId to all 13 business tables
3. Add currentOrganizationId to User
4. Prisma middleware for auto-org filtering
5. TenantMiddleware (header/query/cookie resolution)
6. Migration: seed default org + assign all existing data
7. Seed Free plan + assign to default org
Phase 2: Auth + Org Picker
1. Login returns list of user's orgs
2. POST /auth/select-org { organizationId } → JWT with org context
3. Frontend: org picker page after login
4. JWT payload includes orgId + org-scoped roleId
5. RolesGuard reads role from JWT org context
6. Update AuthProvider with org switching
Phase 3: Admin Panel (User Management)
1. GET /admin/users — list org users
2. POST /admin/users — create user with temp password
3. PATCH /admin/users/:id/role — change org role
4. POST /admin/users/:id/deactivate | /reactivate
5. POST /admin/invites — generate invite code
6. POST /auth/accept-invite — consume invite
7. GET /admin/stats — org user stats
Phase 4: Frontend Admin + Org Context
1. OrgContext provider (React context)
2. API client auto-injects x-organization-id header
3. Org switcher in sidebar header
4. Admin page: user list, create, deactivate, invites
5. All existing CRUD pages scope to current org
6. Settings page: org settings + plan info
Phase 5: Plans + Feature Gating
1. PlanGuard decorator + @RequiresFeature()
2. GET /subscriptions/plans — list available plans
3. POST /subscriptions/select-plan — change plan (admin)
4. Frontend: plan badge in sidebar, feature-gated buttons
5. component for conditional rendering
Phase 6: Payments
1. Create PagoMovilConfig + PagoMovilTransaction models
2. Pago Movil endpoints (banks, initiate, proof, admin review)
3. Stripe integration (checkout session, portal, webhooks)
4. Frontend: billing page, payment history, plan upgrade
Phase 7: Bootstrap / Setup Wizard
1. GET /bootstrap/status — first-run detection
2. POST /bootstrap/setup — create first org + admin user
3. Frontend: setup wizard page on first visit
